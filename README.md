## Selected work

### [ORTUS Apartments](https://ortusapartments.com)

A bilingual property website and private operations platform for a working rental business. The system connects public inquiry flows with protected operational modules, structured data, finance logic and reporting.

### [Luminar Apify Examples](https://github.com/bulatovicluka1989-rgb/luminar-apify-examples)

Runnable JavaScript, Python, PowerShell and n8n examples for public Apify Actors. The repository uses source locks, bounded runs, validation and CI checks while keeping credentials and private Actor internals out of the public code.

### [Google Play feedback → Google Sheets](https://n8n.io/workflows/19396-review-google-play-app-feedback-and-replies-with-apify-and-google-sheets/)

An n8n workflow that collects bounded public review data, verifies run coverage and cost, and updates a durable Google Sheets register through stable keys without creating duplicate rows.
